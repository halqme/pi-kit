---
description: 現在の差分を適切な粒度に分けてすぐにコミットする
---
現在の作業差分を確認し、変更の目的ごとに適切な粒度へ分け、それぞれの内容を端的に表すコミットメッセージでコミットしてください。

このコマンドの実行を、現在の作業内容をコミットする明示的な許可として扱ってください。コミット前の確認は求めず、そのまま実行してください。

作業は次の方針で簡潔に進めてください。

- 判断材料は`git status --shoert` `git diff` と `git diff --cached` の内容に限り、履歴、README、設定、関連ファイルなどを追加で調査しない。
- Skill は追加でロードせず、計画作成、一般的な情報収集、依頼内容の再確認、テストやLintも省略する。
- 差分を変更目的ごとにまとめ、一つのコミットに無関係な変更を混ぜない。必要なら複数のコミットに分ける。
- コミットメッセージは差分から判断し、リポジトリで一般的な簡潔な命令形にする。
- エージェントによる自動コミットとして、各コミットに `Co-authored-by: Pi <agent@pi.dev>` を付ける。
- 署名設定は変更せず、各コミットで `git -c commit.gpgSign=false commit --no-gpg-sign` を使う。
- 差分に秘密情報、明らかな生成物、またはコミットすべきでない内容が見つかった場合だけ停止し、該当箇所を簡潔に報告する。

完了後は、作成したコミットのハッシュと件名だけを簡潔に報告してください。
